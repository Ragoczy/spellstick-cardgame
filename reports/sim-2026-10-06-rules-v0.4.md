# Simulation report — 2026-10-06

1000 games, computer vs computer, seed 1, 2 lanes, card set 0.3-prototype, goals to win 3. Took 53 s.

Generated by `npm run sim`. Nothing in this report has been applied to the rules or cards.

## Findings (written by Claude after reading the numbers)

Rules v0.4 (two actions per turn, the decks as the game clock, a penalty shootout, goalies at
Save 4/3) fixed most of what the first report found:

| | Rules v0.3 | Rules v0.4 |
|---|---|---|
| Draws | 68% | 19% |
| Team A win rate | 41% | 53.5% ✅ |
| Goals per game | 0.36 | 0.77 |

**Still missing:**

1. **Goals per game (0.77; target 1–2).** Two changes reach the target on their own:
   "Tied passes caught" (1.22) and "Goalies Save −1" (1.05). Together (run separately, 1,000
   games each) they give **1.62 goals per game, 14.6% draws, 49% first-player wins, and a 50/50 team
   split** (3 lanes: 1.58 goals, 11.2% draws).
2. **Draws (19%; target under 10%).** Most draws come from 0–0 games where the shootout stays
   level until every player has shot. A bigger penalty bonus barely helps (+2 Shot: 18.2%),
   because both teams benefit equally. More goals in regular play is what reduces ties. Getting under 10% probably
   needs a final tiebreak for when everyone has shot, which is a feel decision.
3. **Turns (23; target 30–50).** Each turn now has two actions, so 23 turns is about 46 actions,
   the same table time as 46 old-style turns. The target was a stand-in for 20–30 minutes, and
   the playtest should check the real time.

**Suggested next step (needs Paul's OK):** make tied passes go to the receiver, and lower the
prototype goalies to Save 3/2. Decide whether a ~15% draw rate is acceptable, or add a final
tiebreak.

## Suggested tuning

- **Goals per game** is 0.77 (target 1–2). Experiments that help most: Goalies Save −1 (1.05 ✅); Tied passes caught + Penalty +2 (1.22 ✅); Save −1 + Penalty +1 (1.05 ✅).
- **Games drawn** is 19.1% (target under 10%). Experiments that help most: Tied passes caught + Penalty +2 (14.6%); Tied passes caught (16.2%); Goalies Save −1 (17.2%).
- **Average turns per game** is 23.1 (target 30–50). Experiments that help most: One action per turn (32.1 ✅); Tied passes caught + Penalty +2 (25.5); Tied passes caught (25.5).

Each row is the same simulation with one change. None of these changes has been made to the game.

| Tied passes caught | 1.22 | 69.5% | 16.2% | 30.9% | 25.5 | 49.4% | 52.4% |

- **One action per turn:** Back to one action per turn (the rules before v0.4).
- **Goalies Save +1:** Goalies back to Save 5 and 4 (before v0.4).
- **Goalies Save −1:** Goalies even weaker: Save 3 and 2.
- **Defense max 5:** No field player has Defense above 5 (the Defense 6 stoppers become 5).
- **Safe catch (forwards):** A forward who catches a pass can't be tackled until their team's next turn.
- **Penalty +1:** Penalty shooters get +1 Shot.
- **Penalty +2:** Penalty shooters get +2 Shot.
- **Tied passes caught + Penalty +2:** Both changes together.
- **Save −1 + Penalty +1:** Goalies Save 3 and 2, and penalty shooters get +1 Shot.
- **Tied passes caught:** A tied pass goes to the receiver instead of the interceptor.
