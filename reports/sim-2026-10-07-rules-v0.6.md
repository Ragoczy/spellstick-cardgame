# Simulation report — 2026-10-07

1000 games, computer vs computer, seed 1, 2 lanes, card set 0.5-prototype, goals to win 3. Took 125 s.

Generated by `npm run sim`. Nothing in this report has been applied to the rules or cards.

## Findings (written by Claude after reading the numbers)

Rules v0.6 adds dice: each player has 5 roll tokens, and calling for dice makes both players roll
a six-sided die (only the caller pays).

- Every target is met except turns (24.5), which is expected with two actions per turn; check table
  time in the playtest. 3 lanes: also every target except turns.
- About 7.4 rolls are spent per game, out of roughly 37 contests, so roughly one contest in five
  involves dice, each time because a player chose it.
- Upsets (the weaker printed card winning) rise from 7% without dice to 11%: dice rescue some
  losing contests without taking over the game (a d6 in every contest would make it 25%).
- Draws fall from 12.5% to 8.4%, mostly because dice break deadlocked shootouts.
